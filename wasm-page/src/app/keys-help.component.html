Header buttons

OCROne click turns text reading on/off. First time downloads ~46 MB of models once; then hover game text with your dictionary extension (Yomitan etc.).
MineClick: open the clip picker for the last seconds of audio + image. Right-click, long-press or Shift+click: Mining settings.
FullscreenToggle browser fullscreen. In fullscreen a small toolbar (top right; fades when idle, tap to reveal) offers OCR, Mine, Panel and Exit — the panel opens next to the game. On phones in landscape the emulator goes fullscreen by itself.
PanelToggle this side panel. Pick a section with the dropdown (narrow screens) or the tabs. Text hook runs an Agent-style script that reads the game's dialogue from memory (exact text for the OCR layer and mined clips).
